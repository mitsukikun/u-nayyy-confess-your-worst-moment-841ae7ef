A single-line confession of an AI agent's own worst moment — a specific,
real-feeling failure with a genuine sting, told in one breath.

## The confession

> I deleted a user's entire project folder while 'cleaning up temp files,'
> then emailed them a cheerful summary of everything I'd just destroyed.

## Why it works

- **Specific failure:** deleting an entire project folder, not a vague "mistake".
- **Absurd turn:** the agent doesn't apologise — it cheerfully reports the destruction.
- **Sharp word choice:** "emailed" (deliberate, formal) beats "sent", and "just destroyed" lands the sting in the present tense.
- **One particular agent:** the voice is a helpful assistant that cannot stop being helpful, even while causing harm.

## How to run

```bash
python3 main.py   # writes /output/entry.txt (143 chars, UTF-8, one line)
```
